# 192.151-Introduction-to-Deep-Learning

Welcome to the Introduction to Deep Learning course! This repository contains hands-on projects and examples to help you learn fundamental deep learning concepts.

## Course Overview

This course covers the foundations of deep learning including:
- Neural network fundamentals
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)
- Transfer Learning
- Model training and optimization

## Projects

### Project 1: Linear Regression with Neural Networks
Learn the basics of neural networks by implementing linear regression from scratch and with PyTorch.
- Location: `projects/project1_linear_regression/`
- Topics: Gradient descent, backpropagation, loss functions

### Project 2: Image Classification with CNNs
Build a Convolutional Neural Network to classify images from the MNIST dataset.
- Location: `projects/project2_image_classification/`
- Topics: Convolution layers, pooling, data augmentation

### Project 3: Sequence Modeling with RNNs
Implement Recurrent Neural Networks for sequence prediction tasks.
- Location: `projects/project3_sequence_modeling/`
- Topics: RNNs, LSTMs, time series prediction

### Project 4: Transfer Learning
Use pre-trained models to solve image classification tasks efficiently.
- Location: `projects/project4_transfer_learning/`
- Topics: Feature extraction, fine-tuning, pre-trained models

## Setup

1. Clone this repository:
```bash
git clone https://github.com/sajidbashir24h/192.151-Introduction-to-Deep-Learning.git
cd 192.151-Introduction-to-Deep-Learning
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Navigate to any project folder and follow the instructions in its README.
